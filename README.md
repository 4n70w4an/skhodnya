# Сходня

Одна страница вместо полусотни вкладок: сервисы, таблицы, Proxmox — с поиском,
группами и проверками доступности.

**alpha 0.0.3**

## Запуск

```bash
python3 server.py
# http://127.0.0.1:8080
```

Из локальной сети: `python3 server.py --host 0.0.0.0`, другой порт: `--port 8081`.

Работает только через сервер: без него страница показывает «Нужен сервер».

## Что внутри

```
index.html      страница
data/           файлы закладок (manifest.js + воркспейсы)
themes/         7 тем + manifest.js
modules/        модули (healthcheck включён)
server.py       локальный сервер
readme.html     полная документация
```

## Основное

- **Поиск** по названию, адресу, заметке, тегу и группе; транслит и опечатки.
- **4 вида**: карточки, плитки, список, группы. В плитках клик раскрывает карточку с проверками.
- **Статусы**: при наведении на карточку справа появляется колонка проверок — каждая в своём прямоугольнике.
- **Правка** по кнопке ✎: группы, элементы, перетаскивание и стрелки ↑/↓, избранное, импорт закладок.
- **Блокировка на запись**: первый открывший — владелец, остальные читают.
- **Темы**: 11 — базовые тёмная/светлая, кремовая, «Бумага», Aurora, Apple (2), Android (2), «Песок», «Графит»; тумблер «Без анимаций».
- **Проверки**: http / https / ping / tcp, интервал 1–3600 с; хост берётся из ссылки.
- **Букмарклет** «＋ в Сходню» работает и в серверном режиме: второе окно пересылает ссылку в основное.
