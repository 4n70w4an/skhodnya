Сходня

Одна страница вместо полусотни вкладок: сервисы, таблицы, Proxmox — с поиском, группами и проверками доступности.

Что это

Сходня — стартовая страница для домашней лаборатории: одностраничное приложение и лёгкий Python-сервер. Ссылки на сервисы сгруппированы по смыслу и лежат в отдельных файлах data/, поэтому их можно править руками, а можно мышью прямо в браузере.

  • лёгкий сервер на Python и статическая страница — без сборки и внешних зависимостей;
  • запись файлов на диск, блокировка от одновременной правки, проверки доступности;
  • ничего не отправляет наружу: ни телеметрии, ни запросов к CDN.

Быстрый старт

Сходня работает только через сервер. Открытие index.html как файла покажет «Нужен сервер»: без бэкенда нет ни записи, ни проверок, ни блокировок.

Запуск

cd start-page
python3 server.py
# Сходня: http://127.0.0.1:8080

Доступ только с этой машины. Чтобы открыть с телефона или другого ПК:

python3 server.py --host 0.0.0.0 --port 8080
Сервер не имеет авторизации. Не выставляйте его в интернет; для домашней сети этого достаточно, для внешнего доступа — только через VPN.

Вариант 3 — на LXC с nginx

Для статики достаточно nginx, но тогда не будет записи и проверок (они требуют server.py). Если нужен полный набор — запускайте server.py как systemd-юнит или в контейнере.

Сервис systemd

Чтобы страница поднималась сама и переживала перезагрузку, есть установщик:

sudo ./deploy/install.sh
sudo HOST=0.0.0.0 PORT=9000 ./deploy/install.sh   # доступ из локальной сети

Скрипт создаёт пользователя skhodnya, копирует проект в /opt/skhodnya, ставит unit и включает автозапуск. Данные при обновлении не перезаписываются. Подробности — deploy/README.md.

Проверки: systemctl status skhodnya, journalctl -u skhodnya -f. Для ping сервису точечно выдаётся CAP_NET_RAW, root не нужен.

Формат файла воркспейса — обычный JSON:

{
  "id": "home",
  "title": "Дом",
  "subtitle": "всё под рукой",
  "groups": [
    { "id": "g1", "title": "Proxmox", "items": [
      { "id": "i1", "title": "PVE 1", "url": "https://192.168.1.10:8006",
        "note": "основной", "tags": ["pve"], "fav": true, "checks": [] }
    ] }
  ]
}

Обязательные поля элемента — title и url. Остальное можно не указывать.

Только JSON: комментарии нельзя, старые *.js больше не поддерживаются. Папку закладок можно сменить в настройках — путь хранится в config.json и в git не попадает.

Воркспейсы

Воркспейс — отдельный набор групп и ссылок: «Дом», «Работа», «Лаборатория». Переключатель — в левом верхнем углу.

Как выбирается при открытии:

  1. ?ws=work в адресе (можно сделать закладку на конкретный воркспейс);
  2. #/work в адресе;
  3. последний открытый — запоминается в браузере;
  4. defaultWorkspace из data/manifest.json;
  5. первый в списке.

Папка закладок. В настройках видно, откуда читаются файлы, и есть кнопка «Выбрать папку…» — окно с деревом папок слева и списком подпапок справа, как в проводнике. Путь можно и вписать руками; выбор подтверждается кнопкой. Путь сохраняется в config.json. По умолчанию разрешены проект и домашняя папка; другие места открываются флагом --browse-root:

python3 server.py --browse-root /srv/bookmarks

Создать воркспейс. Кнопка в настройках создаёт пустой <название>.json в выбранной папке и добавляет его в манифест. Если папка не выбрана, не существует или недоступна для записи — показывается предупреждение с подсказкой.

Сканировать папку. Кнопка находит в папке закладок все *.json с данными воркспейса и предлагает добавить отсутствующие в манифест. Файлы *.personal.* не учитываются.

Если манифеста в папке нет, сервер создаёт его сам при старте и при сканировании — по найденным *.json.

Редактирование

Кнопка ✎ включает режим правки. Без неё изменить ничего нельзя: клики только открывают ссылки. В режиме правки индикаторы доступности скрыты, чтобы не мешать.

  • + Группа — новая группа;
  • + Элемент — карточка: название и ссылка обязательны, заметка, теги, группа, избранное;
  • Импорт закладок — загрузите HTML-экспорт Firefox/Chrome, ссылки попадут в новую группу;
  • ⭐ — в избранное (появится блок сверху);
  • ⧉ — копировать элемент: откроется форма нового элемента с теми же полями;
  • ⠿ — перетаскивание: внутри группы и между группами; заголовки групп тоже перетаскиваются; в режиме правки у карточки есть ↑/↓ — перенести элемент выше или ниже;
  • Сохранить — запись файла через сервер.

Удаление можно отменить кнопкой «Вернуть» в уведомлении. При выходе из правки с несохранёнными изменениями страница предупредит.

Сохранение и блокировки

Блокируется только запись, чтение — всегда свободно. Владелец — тот, кто открыл первым; он шлёт heartbeat каждые 8 секунд, блокировка протухает через 25 секунд.

СитуацияПоведение
Сервер + второе окно«Файл занят»: только чтение, создать копию (сервер сделает файл и запись в манифесте) или забрать управление, если владелец протух.
Без сервераСтраница показывает «Нужен сервер». Запись, блокировки и проверки возможны только через сервер.
Разные серверы на разных машинахНе синхронизируются: побеждает последний записавший.

С сервером сохранение пишет файл атомарно и оставляет .bak с предыдущей версией.

Темы

В настройках ⚙ — одиннадцать тем: тёмная и светлая базовые, кремовая, «Бумага», Aurora с переливающимся фоном, Apple (тёмная и светлая), Android (тёмная и светлая), «Песок» (тёплая светлая) и «Графит» (тёмная нейтральная). Рядом — тумблер «Анимации»: снимает все переходы и переливы, включая Aurora.

Своя тема — это CSS-файл с переменными:

:root[data-theme="my_theme"] {
  --bg:#101418; --panel:#171d26; --panel-2:#1d2530; --line:#27303d;
  --text:#e8eef7; --dim:#8a97a8; --accent:#7c9cff; --accent-2:#3ed6a5;
  --ok:#3fb950; --warn:#d29922; --danger:#f85149;
  --shadow:0 10px 30px rgba(0,0,0,.3);
}

Положите файл в themes/ и добавьте строку в themes/manifest.json:

{ "id": "my_theme", "title": "Моя", "file": "themes/my_theme.css" }

Если тема не загрузилась — страница останется на тёмной, ничего не сломается.

Модули

Модуль — папка в modules/, которую сервер находит сам. HTML и CSS ядра при этом не меняются.

modules/healthcheck/
  module.json   { "id": "...", "entry": "module.py", "assets": ["module.css","module.js"] }
  module.py     def register(api): api.post("/check", handler)
  module.css    стили, всё под своим префиксом
  module.js     window.Svod.registerModule({ id, onRender, editorSection })

Сервер монтирует маршруты по адресу /api/modules/<id>/… и отдаёт файлы модуля как статику. Страница получает список модулей через /api/modules и сама подключает их CSS и JS.

Контракт JS-модуля:

  • Svod.state — состояние приложения (страница, режим, блокировка);
  • Svod.api(path, opts) — запрос к серверу с учётом адреса;
  • Svod.registerModule({ id, onBoot, onRender, editorSection });
  • editorSection(item) возвращает { el, get() } — секцию в редакторе элемента.
Модули работают только через сервер: им нужен /api. Без него страница остаётся рабочей, но без проверок.

Проверки доступности

Модуль healthcheck ставит кружок на карточку, на плитку и на плитку группы (агрегат по всем её сервисам): зелёный — все проверки ок, жёлтый — часть молчит, красный — всё недоступно. При наведении на карточку, плитку или группу справа раскрывается панель со списком проверок. В виде «Список» проверки показываются прямо в строке, без всплывающего окна; на узких экранах индикаторы скрываются.

  • http / https — запрос к адресу элемента; 401/403 считаются «жив» (типично для Proxmox и Dockge); 5xx — недоступно;
  • ping — ICMP до указанного хоста: проверяет, что машина/контейнер отвечает, но не что сервис внутри работает;
  • tcp — открыт ли порт (RDP 3389, SSH 22, 1С и т.п.);
  • проверок у элемента может быть несколько, кнопка «+ проверка»;
  • интервал — своё поле у каждой проверки: по умолчанию 5 секунд, допустимо 1–3600;
  • проверки идут только для приватных адресов и только с сервера; результаты не логируются;
  • при скрытой вкладке опрос приостанавливается.

Хост всегда берётся из ссылки элемента — отдельного поля нет. Для http/https порт берётся из URL, для tcp его можно поправить, для ping порт не нужен.

Для ping нужен системный ping с cap_net_raw (на Ubuntu так по умолчанию). Если прав нет — модуль честно сообщит об этом в подсказке.

Поиск

Ищет по названию, адресу, заметке, тегам и названию группы — «proxmox» находит всю группу. Понимает транслит и мелкие опечатки: проксмокс, докер, пве.

Enter открывает первое совпадение, 1…9 — соответствующее, Esc — сброс.

Вопросы и проблемы

«Манифест не найден»

В выбранной папке нет manifest.json — страница работает на встроенном списке. Нажмите «Скачать шаблон» и положите файл в папку закладок (её путь виден в настройках).

Файл воркспейса не найден

Проверьте путь в манифесте и наличие файла. В режиме сервера путь относительный от папки start-page.

Порт занят

python3 server.py --port 8081

Не сохраняется

Проверьте, что вы владелец блокировки (карандаш активен). Если файл занят другим окном — закройте его или создайте копию.

Нужен сервер

HTML-режим убран: без сервера нет записи и проверок. Запустите python3 server.py.

Тема не применилась

Проверьте путь в themes/manifest.json; при ошибке остаётся тёмная тема.

Ping всегда «недоступно»

Проверьте, что ping -c 1 адрес работает в терминале от того же пользователя, который запускает сервер.

Ограничения

  • нет авторизации: не выставляйте сервер в интернет без VPN;
  • блокировка работает в пределах одного сервера; две разные машины с разными серверами не синхронизируются;
  • проверки — только для приватных адресов (защита от SSRF);
  • без сервера страница не работает — HTML-режим убран;
  • иконки — буквенные; внешние favicon не запрашиваются, чтобы не светить список сервисов наружу.
